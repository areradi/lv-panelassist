# جهت محصول: دستیار طراحی اولیه در کنار EPLAN و AutoCAD

این سند تصمیم‌های مستقیم کاربر در این مرحله را ثبت می‌کند و برای دامنهٔ
خروجی‌ها بر برنامه‌های قبلی ساخت ماکرو و نقشهٔ CAD اولویت دارد.

هدف برنامه کمک به طراحی اولیه است: بررسی داده‌های پروژه، پیشنهاد معماری و
گروه تجهیزات، انجام محاسبات در دامنهٔ پشتیبانی‌شده، نمایش دلایل انتخاب و
کمبود اطلاعات، و تحویل اطلاعات قابل بررسی به ابزارهای اصلی طراحی.
نتیجه‌های مهندسیِ فاقد مرجع و بازبینی همچنان مقدماتی و تأییدنشده می‌مانند.

## تصمیم‌های انجام‌شده

| مورد | تصمیم کاربر و رفتار فعلی |
| --- | --- |
| ماکرو EPLAN `.ema` و `.emp` | حذف از برنامه و بستهٔ خروجی؛ مولدهای فعال از بستهٔ Python حذف شده‌اند. |
| اسکریپت C# ساخت صفحات EPLAN | حذف؛ این مسیر هم بخشی از ساخت ماکرو/نقشهٔ خودکار بود. |
| کیت آزمون ماکروها | حذف همراه مولدهای مربوط؛ آزمون سازگاری دادهٔ قطعات موضوع جداگانه‌ای است. |
| خروجی CAD/DXF | حذف از برنامه و بستهٔ خروجی. برنامه اکنون خروجی DWG/DXF نمی‌سازد. |
| کانکشن‌لیست | تبدیل به ارتباطات کلی تجهیزات: محدوده/فیدر، نوع ارتباط، مبدأ، مقصد، کارکرد و شمارهٔ قطعات پیشنهادی. شمارهٔ سیم، پین، ترمینال، رنگ و سطح مقطع فرضی در این فهرست نیست. |
| تصویر چیدمان داخلی | با انتخاب صریح کاربر، به نمای بلوکی معماری و گروه تجهیزات تبدیل شد؛ بدون جانمایی فیزیکی، مقیاس یا ابعاد ساخت. محاسبات اولیهٔ ظرفیت/فضای تجهیزات حذف نشده‌اند. |

مثال فیدر موتوری: شینهٔ اصلی → حفاظت فیدر → گروه راه‌انداز → موتور.
برای موتور، نیاز پیشنهادی فرمان راه‌اندازی/توقف و دریافت وضعیت/خطا نیز
نشان داده می‌شود. نوع کنترلر، رابط فرمان و ترمینال‌های واقعی جعل نمی‌شوند.
گروه ستاره‌ـ‌مثلث یک بلوک عملکردی است؛ کنتاکتورهای آن به‌صورت مسیر سریِ ساختگی
نمایش داده نمی‌شوند. برقگیر در صورت پیشنهادشدن، یک انشعاب جداست.

این فهرست، فهرست سیم‌بندی اجرایی یا تأیید کامل مدار حفاظتی نیست. مسیر PE،
مدار ایمنی، جزئیات سازنده، شماره‌گذاری و اتصال نهایی در EPLAN یا AutoCAD باید
طراحی و بازبینی شوند. قطعات نمایش‌داده‌شده همان پیشنهادهای محاسبهٔ فعلی‌اند؛
وجود شمارهٔ قطعه به‌معنی تأیید انتخاب نیست.

## مواردی که هنوز باید تک‌به‌تک درباره‌شان تصمیم بگیریم

| خروجی موجود | وضعیت تصمیم محصول |
| --- | --- |
| گزارش محاسبات Excel | فعلاً حفظ؛ محتوا و ستون‌های لازم با کاربر بررسی شود. |
| گزارش HTML / PDF | فعلاً حفظ؛ دربارهٔ قالب‌های واقعاً لازم تصمیم بگیریم. |
| چک‌لیست تأیید طراحی | فعلاً حفظ با وضعیت مقدماتی؛ امکان ادغام در گزارش بررسی شود. |
| نقشهٔ تک‌خطی SVG | فعلاً حفظ؛ کیفیت و نقش آن به‌عنوان نمای اولیه بررسی شود. |
| نمودار زمان–جریان کلیدها (TCC) | فعلاً حفظ؛ کاربرد و دامنهٔ تخمینی آن بررسی شود. |
| نقشهٔ مدار فرمان SVG و پیش‌نمایش‌های IEC | فعلاً حفظ برای بررسی؛ تصمیم حذف یا ساده‌سازی هنوز گرفته نشده است. فهرست ارتباطات زیر پیش‌نمایش اکنون کلی است. |
| BOM CSV و Parts Management CSV | فعلاً حفظ؛ دربارهٔ نیاز به هر دو، فیلدهای تبادل و نگاشت دستی در ابزار مقصد تصمیم بگیریم. ورود مستقیم به EPLAN تضمین نشده است. |
| بستهٔ ZIP | فعلاً حفظ؛ شامل خروجی‌های باقی‌مانده است و ماکرو، اسکریپت یا CAD ندارد. |

هیچ مورد از جدول بالا بدون تصمیم بعدی کاربر حذف نمی‌شود. موارد بعدی را
یکی‌یکی، با نشان‌دادن نمونه و توضیح کاربرد بررسی می‌کنیم.

## فایل‌ها و سازگاری

- کانکشن‌لیست مستقل: `06_Functional_Connections.csv`؛ همان داده در رابط
  برنامه، برگهٔ `05_Functional_Connections` اکسل و گزارش HTML/PDF دیده می‌شود.
- نمای معماری: `07_Architecture_Overview.svg`؛ در منو «معماری بلوکی» نام دارد.
- API قدیمی `ControlCircuitGenerator.export_connections_csv` نیز اکنون فهرست
  کلی تولید می‌کند؛ فایل سیم‌بندی عددی تولید نمی‌کند. ساختار CSV عمداً تغییر
  کرده و نگاشت قدیمی پین/سیم باید کنار گذاشته شود.
- بسته بدون PDF، مستقل از تعداد فیدر، ۱۳ فایل دارد؛ با PDF موفق، ۱۴ فایل.
  شمارهٔ بعضی نام‌ها برای پایداری خروجی‌های حفظ‌شده پیوسته نیست.
- فایل‌های پروژه، خروجی‌های قبلی و پوشهٔ بازیابی کاربر پاک نشده‌اند. کد
  حذف‌شده در تاریخچهٔ Git قابل بازیابی است، اما جزو برنامهٔ فعال نیست.
- با تغییر نسخهٔ محاسبه/کد، برای خروجی تازه باید دوباره محاسبه کرد. کنترل
  تازگی، snapshot ثابت و نوشتن اتمیک خروجی‌ها حفظ شده‌اند.
